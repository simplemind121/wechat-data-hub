派生结果与原始消息/附件分开保存，原始字节不改写。OCR/ASR 结果可关键词检索；AI 结果只在业务许可仍有效时可读。取消、关闭、租约失效或计算过程中撤销许可均不允许迟到结果写入。长计算不持有数据库行锁，LLM 进程通过私有卷文件锁协调内存。恢复后的模块默认为关闭。向量原始派生 JSON 保存于核心备份，可重建独立 pgvector 缓存。

模型不因启动而隐式下载。公开固定模型/引擎的 URL、字节数、SHA、许可见 apps/api/wdh_api/model_assets.json；本地推理子进程没有数据库或 Odoo 密钥，HTTP 模型接口仅临时回环监听，禁用 Web UI、遥测及代理继承。没有云 AI 提供方，也没有远端 Odoo 写入代码。

实际测试与范围见 TEST_EVIDENCE.md。全部测试输入为自制合成数据，未使用真实聊天。相似度、OCR 算法评分、模型输出均不等同于业务事实正确性。
