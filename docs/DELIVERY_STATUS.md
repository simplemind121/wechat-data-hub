# 交付状态 · 0.3.0 本地识别与 AI 可用版

本版在 0.2 核心应用上增加本地图片 OCR、语音转录、语义与关键词融合检索、带引用的证据问答、AI 摘要和业务候选审核。所有模块默认关闭；不需要云 API 密钥。首次管理员由用户创建，运行包不包含聊天、账号、密钥或数据卷。它是可用的增量版本，正式 RC 的剩余门槛仍列在 ACCEPTANCE_STATUS.md。

| 能力 | 当前结果 |
| --- | --- |
| 核心导入、归档、来源、复核、检索、导出、RBAC | 沿用并回归验证；JSONL/JSON/CSV/ZIP 与明确 manifest/字段映射 |
| 图片 OCR | Tesseract + 固定 SHA 中文/英文模型；PNG/JPEG/WebP/静态 GIF；文字、原图词框、模型版本、原图哈希、证据导出与关键词搜索 |
| 语音转录 | 本地 Whisper tiny + sherpa-onnx；实际 WAV/OGG/FLAC/MP3 转录；片段时间、原音频播放定位、机器结果提示；不支持的 SILK/AMR 不假称可解码 |
| 语义/混合检索 | BGE 中文 512 维本地向量，PostgreSQL pgvector；关键词与余弦候选 RRF 融合；先按 workspace/业务许可筛选，再排序；返回原消息/识别文本引用 |
| 证据问答 | 本地 Qwen 选择直接相关证据，服务端返回真实来源摘录；无证据明确无法确定；计算后再次检查许可；相似度不是事实可信度 |
| AI 摘要/候选 | 有来源跨度的摘录摘要与客户/供应商/产品/报价/采购意向/订单/任务候选 schema；非法或无来源字段拦截；始终待人工审核，可拒绝或按来源修改 |
| 模块生命周期 | 管理员逐项下载安装/启停；模型 SHA 校验；持久任务/取消/重试/租约防重复写入；LLM 跨 API/worker 的内存并发保护 |
| 加密备份/恢复 | 新结果、来源关联和向量重建证据纳入备份；恢复后所有处理模块关闭，旧会话失效；模型权重另行安装，向量缓存可重建 |
| Odoo 本地预览 | 已审核且仍有业务许可的实体才能预览；按实体类型区分目标模型；零外部写入 |
| Odoo 只读联调入口 | 管理员显式配置后可查版本、Community/Enterprise、模型字段和读/创建权限；仅契约测试通过，真实实例未提供，实际联调 BLOCKED |
| 真实数据适配 | 通用合同与合成样例通过；实际 iPhone/Mac/Windows 导出器/版本全部仍 BLOCKED，独立验证见 REAL_VALIDATION.md |
| 剩余原规格 | Odoo outbox/真实草稿投递与回读、parser 派生版本审批切换、完整故障监控、OS 安全审计等尚未全部完成 |

运行包自带 OCR 模型和本地推理引擎。ASR、embedding、LLM 权重需管理员在设置页主动下载一次，分别约 99MB、26MB、469MB；下载后可离线推理。完整 AI 建议至少 8GB 内存；已通过109项PG回归、6项源码及6项实际成品浏览器流程。本次交付运行镜像为 Linux amd64，Windows/macOS Docker Desktop 实机尚未验证。

使用：解压完整包，执行 `bash start-offline.sh`，打开 http://127.0.0.1:5173。进入「设置 → 本地识别模块」启用 OCR，下载并启用需要的其他模型；会话详情中的按钮执行图片/语音处理。AI 还需管理员先允许该会话进行业务处理。操作步骤见 RUNBOOK.md。
