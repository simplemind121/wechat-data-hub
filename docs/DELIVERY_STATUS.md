# 交付状态 · 0.2.0 本地核心可用版

本版已完成可实际操作的核心应用，运行方式是 Docker Compose + 本地 PostgreSQL + 私有原件卷。首次管理员由用户设置；交付包无账号密码、聊天或数据卷。它不是最初只有健康页面的 0.1.0，也没有满足原规格全部模块的正式 RC 条件。

| 能力 | 当前结果 |
| --- | --- |
| JSONL / JSON / CSV、ZIP 媒体与 manifest | 已实现并测试；没有 manifest 可由用户声明来源，服务计算实际文件哈希 |
| 持久 worker、进度、错误隔离、重试/取消、幂等 | 已实现；数据库租约/分块事务，不把上传请求作为后台作业 |
| 原件保全、消息/附件/联系人、浏览/检索/导出 | 已实现；每条消息可回查来源，附件缺失明确显示 |
| 强/弱匹配与人工复核、身份映射、审计 | 已实现；只有合成认证 namespace 可自动强匹配，真实 exporter ID 不盲信 |
| 本地认证、RBAC、workspace、隐私标签 | 已实现并有越权/CSRF/登录限速测试 |
| 加密备份与新目标恢复 | 已实现；真实 PostgreSQL → 新 PostgreSQL 恢复及媒体哈希核验通过 |
| 报价候选与 Odoo 预览 | 本地规则、有证据审批；仅 dry-run、零外部写入 |
| parser 重处理 | 无损差异预览已实现；批准后切换派生版本未实现 |
| OCR / ASR / embedding / RAG / LLM | 未实现，默认关闭，无模型下载或外部调用 |
| Odoo 19 CE 真实连接、outbox/重试/写入 | 未实现；无获授权实例，不宣称已联调 |
| 真实微信客户端/导出器兼容 | BLOCKED，无真实样本；只验证通用数据合同和合成样例 |
| 正式 RC / 全规格生产交付 | BLOCKED，上述 REQUIRED 模块和真实兼容门槛未全过 |

运行依赖 Python/npm 漏洞审计未检出已知问题。开发工具链尚有 picomatch ReDoS（5个 high 派生报告，1个根因），截至审计可用最新 4.0.7 仍在影响范围；仅开发/构建工具，不进入 nginx 成品镜像。上游补丁、完整 OS 镜像审计及独立密码学审查仍需跟进，不能声称全栈无漏洞。细节见 `TEST_EVIDENCE.md`。

安装：完整包解压后 `bash start-offline.sh`，打开 http://127.0.0.1:5173。支持边界、测试和恢复说明随包保存；不需要继续开发就能使用上表已完成的核心功能。
